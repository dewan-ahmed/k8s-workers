# Blockcraft theme

Original CSS and SVG artwork for the Kubernetes toolkit. The block landscape,
terrain patterns, and interface iconography are original work, not game assets.
Pixelify Sans is by the Pixelify Sans Project Authors, distributed under the
SIL Open Font License in `OFL.txt`. It is self-hosted; no font service is called.

Run `npm run sync:theme` to copy these assets into each Worker's public directory.
`npm ci`, workspace `dev`, and workspace `deploy` run this automatically.
Generated `public/theme` directories are not committed.
