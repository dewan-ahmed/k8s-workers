02 / RESULTS

Upgrade report

Deprecated

    Sends findings and migration notes, not your raw files. On Workers Free, only verified destinations can receive reports.

    Use from CI / terminal

    Send a manifest or rendered Helm output directly to POST /api/check:

    curl -fsS 'https://deprecations.k8s.workers.dev/api/check?targetVersion=1.25' \
  -H 'Content-Type: application/yaml' --data-binary @manifest.yaml -o report.json

    Raw uploads require the targetVersion query parameter and also accept application/x-yaml, text/yaml, and text/plain. For JSON, include the target and manifest in the body:

    curl -fsS https://deprecations.k8s.workers.dev/api/check \
  -H 'Content-Type: application/json' \
  --data-binary '{"targetVersion":"1.25","manifest":"apiVersion: batch/v1beta1\nkind: CronJob"}'

    The JSON report includes targetVersion, mode, scannedResources, removed, deprecated, findings, and warnings.

    HTTP 200 means a report was produced, even with removals or skipped YAML. Errors return JSON with an error message: 400 invalid input, 403 cross-origin POST, 405 wrong method, 413 size or resource limit, 415 unsupported content type, 429 rate limit, or 500 unexpected scan failure. See GET /api/config for supported targets.

    Stop if curl fails. After a successful manifest scan saved to report.json, fail CI on removals, warnings, or zero scanned resources:

    jq -e '.scannedResources > 0 and .removed == 0 and (.warnings | length == 0)' report.json

    Chart archives always include a static-scan warning. Use this strict gate on rendered manifests, not archive reports.

    API lifecycle data from the Kubernetes project. For other checks, use the cluster compatibility checker or the schema validator.
